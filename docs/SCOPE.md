# Scope and excluded records

This release contains 62 selected original files: 42 project component files and 20 upstream vendor files (five files repeated across four component directories). All 62 are byte-identical to their preserved sources. New packaging documents, licensing notices, verification tooling and replay evidence are separately inventoried.

Included: selected frozen specifications, wrappers, schemas, bounded helpers, synthetic deterministic fixtures/tests, required B schema bindings, Operator R2.1 and two R3.1 normative supplements. The upstream rfc8785 license, metadata and adaptation notices remain in each vendor copy.

Excluded: raw reviewer/probe responses, comparison/adjudication quotation records, historical logs and red baselines, private browser evidence, account data, corpus material, D01–D12/NENV examples, private PDFs, assessments, historical execution scripts, and prior packaging records. Exclusion does not imply destruction or a finding of infringement; the complete internal records remain unchanged.

Original freeze manifest digests in provenance identify the source snapshots, but this subset is not a complete export of those manifests. Public inventory hashes describe this package. Historical references inside unchanged normative artifacts are retained as source context; omitted history is unavailable in this distribution. No references are rewritten to imply otherwise.

Three controlled assessment attempts stopped in preflight; no successful controlled assessment is asserted. The user's controlled-assessment branch is closed without loosening tools_available=[]. No transport qualification is granted by this distribution.
